# Brasa Viva — Codex guide pack

Coloca estos archivos en la raíz del repositorio de Brasa Viva.

Punto de entrada: `AGENTS.md`.

Orden recomendado para Codex:
1. `AGENTS.md`
2. `ARCHITECTURE.md`
3. documento de `docs/` relacionado con la tarea
4. `.agent/PLANS.md` para trabajo complejo

No contiene código de aplicación. Contiene instrucciones persistentes, arquitectura,
reglas de dominio, criterios de calidad y plantillas para ejecución.
